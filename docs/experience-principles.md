# エールステーションの体験を守る方針

## 入室から曲まで

- ゲストはスタジオに入り、DJ YOSHIの挨拶から会話を始める。番組の冒頭で、聞いた話からその人だけの一曲を届けると伝える。
- 通常の進行はDJとの会話だけで進める。題材の確認、生成開始、楽曲ページへの移動など、進行のための操作ボタンは増やさない。
- 曲の制作は裏で進める。音源を読み込めたら、会話の区切りを待ち、DJの曲紹介が終わってから曲のページへ移って再生する。ゲストの発話を途中で切らない。
- 制作や接続の細かい処理状況は、ゲスト向け画面やDJの台詞に出さない。開発時は進行表示で確認する。
- 終了操作や、接続・音源読み込みの失敗、自動再生の制限に備えた操作は残せる。通常の進行で押してもらう操作とは区別する。
- 一曲は最後まで一度聴く体験にする。最後まで再生したら締めの言葉と入口に戻る操作を出す。
- 演出や追加機能の自動化が不安定で、実現するには通常進行に操作を増やす必要がある場合は、その機能を見送る。再生や終了など、体験を成立させるための復帰手段は使えるようにする。

## 会話と曲

- 会場の話は挨拶の一往復。DJが曲にしてみたい場面を尋ねた後、本人が題材として話した内容を曲に活かす。場面が浮かばないときだけ、思い出す手がかりを二つほど添える。

- 会話は短い受け答えで進める。答えを聞きたいときは、ゲストが何を答えればいいか分かる質問を一つ返す。時間や質問回数だけで会話を強制終了しない。
- 聞いていない出来事や気持ちを事実として歌わない。本人が話した言葉や場面を活かし、曲調や比喩には創作の幅を残す。
- ゲストのラジオネームはDJが呼びかけるときに使う。歌詞に入れない方針で試作し、例外を設けるかは聴き比べで決める。
